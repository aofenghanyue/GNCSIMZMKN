# Packages

这里放可复用的领域、模型、算法和工作流贡献。进入可发布范围前，每个 package 需要 manifest、稳定 identity、contracts、assets、verification 和 license/provenance。

G1 已通过。`yyz-rigid-step` 是当前首个 R1 产品 package：它以 experimental identity 直接消费 Contracts 与 Foundation，并由现有 R0 YYZ fixture/oracle 验证一步 candidate。通用 package manifest、Catalog 接入和兼容协议等到对应真实 consumer 出现时再实现。
