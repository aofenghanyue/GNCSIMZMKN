# Scientific and behavior oracles

Oracles provide independent facts used to accept, reject or explain an implementation result. Legacy output can seed evidence capture; final scientific authority comes from analytic results, paper data, independent implementation, convergence or approved engineering reference.

`oracle-manifest.json` starts with the seven preserved runtime claims listed by the target blueprint. All entries remain `planned` until R0 produces executable inputs and expected facts.

The general manifest therefore uses the explicit
`gnczmkn.oracle-manifest.placeholder/0` version and remains gate-blocked. The
independently reviewed scientific-conventions manifest conforms to
`gnczmkn.oracle-manifest/1`; its provenance, expected facts, tolerance text, and
source references are validated by the R0 schema command.
