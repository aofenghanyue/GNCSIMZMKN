# 新成员 onboarding checklist

- [ ] 获得仓库和 legacy archive 的授权访问。
- [ ] 完成 README、项目章程和 greenfield 边界阅读。
- [ ] 完成 00、00A、02、15、11 主线阅读。
- [ ] 运行 `tools/bootstrap.ps1`。
- [ ] 能说明 Plan、Commit、Artifact/Control 三道防火墙。
- [ ] 能说明当前 gate 与禁止提前建设的能力。
- [ ] 能从 backlog 找到一个 `ready` 任务及其 acceptance/evidence。
- [ ] 知道科学差异、ADR 和 gate decision 的记录位置。
- [ ] 与 owner role 负责人完成首次范围确认。
