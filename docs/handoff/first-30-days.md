# 首月安排

## 第 1 周：建立共同事实

- 填写角色指派；
- 全员完成架构阅读路线；
- 验证新仓库 bootstrap；
- 验证 legacy archive hash 和可解包性；
- 冻结工具链、许可证和保密范围的 ADR proposal；
- 启动 R0-GOV-001、R0-LEG-001、R0-SCI-001。

## 第 2 周：建立 oracle 结构

- 提取现有 publish、phase、continuous group、record/stop 和 SimFlow 行为；
- 建立 quaternion/frame/unit property tests；
- 定义 oracle manifest、容差和 provenance；
- 选择 minimal 3DoF fixture 的输入和解析 reference。

## 第 3 周：闭合纵向 reference

- 建立 YYZ 输入、资产、公式中间量和 termination reference；
- 建立 CAVH Eq17/Eq18 论文来源和独立计算；
- 将 00A 示例转为机器可校验 fixture；
- 建立 PlanProofRecord schema proposal。

## 第 4 周：R0 预评审

- 运行 glossary/link/schema/task checks；
- 演练 G0/G1 gate；
- 分类所有无法解释的新旧差异；
- 将未闭合项转为 backlog 或 ADR；
- 只在 G0/G1 通过后解锁 R1。

首月不以新增框架类数量衡量进度。可执行 reference、明确 owner 和可审查决策构成主要产出。
