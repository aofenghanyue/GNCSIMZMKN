# ADR-0012: Eigen 3.4.0 canonical numeric storage

- Status: Accepted
- Date: 2026-08-15
- Owner: Repository owner
- Related task: R1-FND-001
- Related decision: D-004
- Architecture reference: 03 §4、§5、§12

## Context

R1 Foundation 已经交付统一数值结果、固定步 RK4、三线性插值、标量求根和 YYZ 完整惯量张量的固定 `3×3` 对称正定求解。后续直接 consumer 包括 R0 科学约定的四元数性质与 YYZ 6DoF 的姿态导数、体轴力旋转和 principal-spin 收敛。架构 03 将 Eigen 定为 L1 规范数值存储底座，并要求四元数约定与数值策略显式可查。

D-004 的默认约束在 ADR 形成前禁止加入第三方依赖。仓库已有 Eigen 3.4.0 官方归档的版本、来源、字节数、SHA-256 和上游许可证说明；该归档此前只用于隔离 Legacy 复现。仓库所有者已要求集中开发科学内容，并允许后续推荐项按默认接受记录。

## Decision

1. R1 Foundation 锁定 Eigen `3.4.0`，作为必须的 header-only 构建依赖。源码与安装目录位于 Git 忽略的 `build/dependencies/`，不 vendoring 到仓库。
2. CMake 通过 `find_package(Eigen3 3.4.0 EXACT CONFIG REQUIRED)` 消费 `Eigen3::Eigen`。其他 Eigen 版本会在配置阶段失败。
3. `gnc::foundation::Vec3`、`Mat3`、`Vector`、`Matrix` 和 `QuaternionStorage` 形成当前规范数值存储别名。三维向量采用列向量，固定矩阵采用 Eigen 默认列主序，四元数采用 `Eigen::Quaterniond`。公共转换函数逐项映射 `[w,x,y,z]`，调用方不得把 Eigen 内部 `coeffs()` 的 `[x,y,z,w]` 顺序用作 wire order。高层领域端口继续使用带语义的领域类型。
4. `tools/install-eigen.ps1` 只接受字节数 `3704940` 且 SHA-256 为 `eba3f3d414d2f8cba2919c78ec6daab08fc71ba2ba4ae502b7e5d4d99fc02cda` 的官方 3.4.0 ZIP。CI 在构建目录安装该依赖，本地开发可以复用同一脚本或兼容的外部安装。
5. 首个产品线性代数入口固定为 `solve_spd_3x3(A,b,policy)`。它使用规范存储、显式 Cholesky、1-范数条件估计和无穷范数残差；对称化只在 policy 容差内发生，并返回 `Approximate` 与 `Symmetrized` flag。自动 fallback 不进入本切片。
6. `passive_quaternion.hpp` 直接实现 ADR-0007：Hamilton 乘法、真实逆元被动旋转、`q_c_a=q_b_a*q_c_b` 组合、body/inertial rate 导数和 `q/-q` 等价姿态误差统一返回 `NumericalOutcome`。非单位输入由 `Error` 或 `NormalizeWithFlag` 显式处理；Euler 与 frame/time 语义不进入 Foundation。
7. JSON/YAML 与测试库的版本选择继续开放。Eigen 升级、替换、vendoring 或进入 release bundle 需要直接修订本决定。
8. ADR-0008 的 public GitHub 协作范围保持不变。当前没有通用外部分发许可，产品 release 与平台外 bundle 继续阻断。

## Consequences

- R1 获得与目标架构一致的唯一数值存储底座，后续矩阵算法无需引入平行 `std::array` 公共表示。
- YYZ 完整惯量 consumer 可以直接验证 products of inertia、缩放不变性、残差、条件估计、奇异/非正定/病态失败。
- 科学约定与 YYZ 6DoF 现在直接回归同一产品四元数实现；显式 wire mapping 阻断 Eigen 内部系数顺序泄漏，五级 principal-spin 轨迹持续检查四阶收敛和候选四元数范数残差。
- Eigen 成为配置阶段的显式先决条件。离线环境需要提前提供已校验归档或兼容安装目录。
- 动态分解、稀疏矩阵和通用维度 solve 保留给各自具有 consumer 的后续切片。
