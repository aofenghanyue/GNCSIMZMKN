## 失败路径

- 列/行向量、主动/被动旋转、`to/from` 方向或 Hamilton 乘法任一漂移时失败；
- 四元数组合不满足 `R_c_a = R_c_b * R_b_a` 与 `q_c_a = q_b_a * q_c_b` 时失败；
- 序列化不是精确 `[w, x, y, z]`、`q`/`-q` 不等价或零模四元数未拒绝时失败；
- 四元数系数不是恰好四个有限值，或非单位输入未显式选择 `Error`/`NormalizeWithFlag` 并记录 correction flag 时失败；
- 运行时规范单位不是 SI/弧度，或 offset unit 未在边界显式转换时失败；
- 单位转换接受未知单位、非有限值、溢出或低于绝对零度的温度时失败；
- point/free-vector 变换类别混淆，或领域向量缺少 expressed-in/reference frame 语义时失败；
- 固定步长通过重复浮点加法推进，或 tick、SimulationTime、Duration、SampleTime、ValidTime、WallTime 被合并为无标签 `double` 时失败；
- clock domain 缺失/混用、时间值非有限、validity 区间反向或半开端点语义漂移时失败；
- C++ 与 Python 的 check identity、状态或数值超出 fixture 容差时失败；
- 任一 required check 没有执行断言却报告通过时失败；
- Python 参考导入项目代码、Legacy、NumPy/SciPy 或其他第三方实现时失败；
- fixture、参考实现、测试源或已审查报告的 hash 漂移时失败；
- 修改冻结 Legacy，或把验证 spike 放入 `framework/`、`packages/`、`adapters/`、`apps/`、`user/` 产品路径时失败。
