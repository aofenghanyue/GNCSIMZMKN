## 准备结论

`REF-CAVH-FORMULA-001` 当前只是 `specification_only` seed。现有 Legacy 代码能够运行，现有单元测试也能通过，但这两件事不能证明 Eq. (17)、Eq. (18)、最优升阻比包线、Mach 导数或 TDCT 符合论文：测试中的 `paperEq17GammaCommand` 与 `paperEq18GammaCommand` 实际复制了生产头文件中的同一套代数，形成同源循环校验；冻结任务使用的气动 CSV、另一份“paper aero”曲线和任务参数均没有论文页码、提取方法、不确定度或授权记录。

出版物元数据审计找到了一个高可信候选主来源：Wenbin Yu 与 Wanchun Chen，*Guidance Scheme for Glide Range Maximization of a Hypersonic Vehicle*，AIAA 2011-6714，DOI [`10.2514/6.2011-6714`](https://doi.org/10.2514/6.2011-6714)；[北京航空航天大学作者成果页](https://teacher.buaa.edu.cn/yuwenbin/zh_CN/lwcg/157999/content/19603.htm)也给出相同题名、作者、会议和 DOI。另有后续 Springer 章节 *Trajectory Damping Control Technique for Hypersonic Glide Reentry*，DOI [`10.1007/978-981-15-8901-0_9`](https://doi.org/10.1007/978-981-15-8901-0_9)。但是，本仓库尚无经授权的原文 bytes、版本/页码映射、公式转录、license disposition 或 source hash，因此不能断言冻结代码中的 “Eq17/Eq18/Eq19” 已对应其中任一出版版本。

本准备包把三条不可互相替代的科学 artifact lane、单独的 Frozen Legacy behavior lane、12 项 authority decision、公式/intermediate 账本、独立计算策略、domain/status 设计、逐字段 tolerance 和 20 项 mutation 收敛为可领取设计。详细设计见 [CAVH formula reference bundle 设计](../../quality/cavh-formula-reference-design.md)。本切片没有修改 backlog、fixture、schema、产品代码或冻结 Legacy，也不构成 `R0-SCI-004` 完成、论文公式获批或 G1 通过证据。
