## 失败路径

- ZIP、manifest 与 checksum 任一 identity/hash 不一致时停止，不解包；
- 工作目录不在仓库 `build/legacy-reproduction/` 下或已经存在时停止，避免覆盖证据；
- CMake、编译器、generator 或 Eigen 缺失/版本不满足时记录环境 gap，不伪造成功；
- configure/build 非零退出时保留完整日志、命令和阶段状态；
- CTest 失败时记录 test name、label、working directory 和输出，并从声明目录定向复跑；
- representative mission 非零退出、预期 CSV/summary 缺失或输出路径越界时失败；
- 每份 evidence 文件在报告发布前计算 SHA-256，缺失或 hash 漂移时失败；
- Legacy 非产物文件、冻结 archive、新仓库 include/runtime 始终零修改、零依赖；只允许在隔离源码树生成 `user/outputs/**` 与测试声明的 `test_outputs/**`。
