# 阶段地图

```text
Bootstrap
  -> R0 oracle / contracts / guards
  -> R1 foundation / model ecosystem
  -> R2 semantic compiler / plan firewall
  -> R3 transactional session / M1
  -> R4 evidence firewall
  -> R5 research workflow / M2
  -> R6 experiment / Python
  -> R7 controlled authoring
  -> R8 realtime adapters / M3
```

| 阶段 | 主要权威输出 | Gate |
| --- | --- | --- |
| R0 | oracles、schemas、guards、decision baseline | G0/G1 |
| R1 | definitions、contracts、recipes、verified packages | G2 |
| R2 | Canonical Model Graph、Descriptor、ProofIndex、Image | G3 |
| R3 | ModelCommit、ObservationSeal、RunOutcome | G4/G5/G6 |
| R4 | ArtifactRef、LineageEdge、RunManifest | G7 |
| R5 | WorkflowPlan、TaskOutcome、EvidenceBundle | G8 |
| R6 | Experiment、CaseManifest、Python Session | G9 |
| R7 | ResearchProposal、OperationReceipt、Blueprint source | G10 authoring |
| R8 | Command、RenderSnapshot、backend receipts | G10 realtime |
